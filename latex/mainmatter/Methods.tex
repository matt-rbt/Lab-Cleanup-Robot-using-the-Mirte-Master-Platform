\section{Methodology}
\begin{paracol}
    {2}

    This study follows factorial experimental design, analyzing the interplay
    between perception, coverage and system level decision making.

    Three independent variables are defined:

    \begin{itemize}
        \item Perception quality
              \begin{itemize}
                  \item Classical cv based classification
                  \item Model based classification
              \end{itemize}
        \item Detection method
              \begin{itemize}
                  \item point cloud clustering
                  \item depth projection
              \end{itemize}
        \item Coverage strategy
              \begin{itemize}
                  \item Systematic Coverage following a predefined path
                  \item Reactive Coverage by acting in real time
              \end{itemize}
        \item System-level strategy
              \begin{itemize}
                  \item Clean-as-you-go
                  \item Map-then-optimize
              \end{itemize}
    \end{itemize}

    This results in a total of 16 experimental configurations, however some of
    these setups are fundamentally incompatible, such as Systematic coverage with a
    clean as you go approach. The full setup is shown in table x.
