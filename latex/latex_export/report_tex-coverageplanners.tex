\paragraph{The Free Space Polygon}

Each defined navigator must update its internal map and as a result plan a path over this map.

A function ``\texttt{update\_map()}'' first takes the costmap and, given a threshold, sets the free space to 0 and occupied space to 1. It then detects the boundaries of the free space and saves these as contours.

\paragraph{Boustrophedon Coverage}

The first navigator that will be covered is a Boustrophedon based coverage planner. \newline
This navigator plans in two steps:

\begin{itemize}
\item Decomposition
\item Swath Generation
\end{itemize}

\subparagraph{Boustrophedon Cellular Decomposition}

To effectively cover the entire map with boustrophedon (back and forth) swaths, the map is first partitioned (decomposed) into smalller areas that can be covered fully with these swaths. This is done by sweeping a straight line across the map and creating new cells where the connectivity of this line decreases. \subparagraph{Boustrophedon Path Generation}

After decomposition, each cell is populated with a boustrophedon path. Swaths are generated as straight lines parallel to the line used during decomposition. The transitions, often called headlands, are then generated to create one continuous path inside the cell.

\paragraph{SkeletonPath}

The \texttt{SkeletonPath} planner is a topology-based coverage planner that generates navigation paths using the morphological skeleton of the environment. Unlike the \texttt{BousPath} planner, which decomposes the free space into sweepable cells, the skeleton planner reduces the free space to a graph-like centerline representation. This representation preserves the connectivity of the environment while simplifying path planning. The implementation is inspired by recent work in morphology-based exploration and autonomous navigation.

\subparagraph{Path Planning}

After the waypoints have been generated, they are then sampled and ordered. The algorithm does this by first constructing a graph representation of the skeleton tree. The waypoints then become graph nodes. Edges are generated between the nodes with a certain distance threshold. To efficiently identify neighboring points, a k-d tree is used for spatial indexing. Starting from the closest waypoint to the robot, the algorithm recursively explores nearby nodes and connects them within the graph. Leaf nodes are then identified in the tree, (nodes with one connection).

\includegraphics[width=0.7\linewidth]{files/4599d3c4df780082d726948f94d0cc2d.png}

\subparagraph{Path Ordering}

First the closest leaf node to the robot is found, this is the starting position. \newline
The planner traces a path along the tree and selects the shortest one to the next leaf node. \newline
It then appends these points to the path and sets this new leaf node as the current one and marks it as visited. \newline
The algorithm repeats this process untill all leaf nodes have been explored successfully.
