\section{Experimental Methods}

This study follows factorial experimental design, analyzing the interplay between
perception, coverage and system level decision making.

Two independent variables are defined:

\begin{itemize}
\item detection method

\begin{itemize}
\item Point cloud clustering
\item 2D Depth projection
\end{itemize}


\item coverage strategy

\begin{itemize}
\item Boustrophedon Coverage
\item Morphology based skeleton Coverage
\item Spanning tree coverage
\end{itemize}
\end{itemize}
