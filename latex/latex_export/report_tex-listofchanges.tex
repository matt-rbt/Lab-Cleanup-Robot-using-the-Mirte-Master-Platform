\subsection{MIRTE Modifications and Setup Guide}

\paragraph{Clock Synchronization}

To syncronise the two machines' clocks, use the following command:

\begin{verbatim}
sudo date -s "date_and_time"
\end{verbatim}

example:

\begin{verbatim}
sudo date -s "2026 -01 -01 12:01:01"
\end{verbatim}

Install image pipeline:

\begin{verbatim}
sudo apt install ros -humble -image -pipeline
\end{verbatim}

\subsubsection{Setting up the MIRTE Master}

Insert an SD card with an image into the MIRTE.
Wait for flashing to conclude.

Turn on the MIRTE Master and wait for the hotspot to turn on.
Connect to the MIRTE's wifi.

On your pc, insert the command:

\begin{verbatim}
ssh mirte@mirte_local
\end{verbatim}

and insert the password:

\begin{verbatim}
mirte_mirte
\end{verbatim}

If necessary, switch motor pins in:

\begin{verbatim}
home/mirte/mirte_ws/src/mirte -ros -packages/mirte_bringup/telemetrix_config/mirte_master_config.yaml
\end{verbatim}

On the MIRTE, change the PID values in:

\begin{verbatim}
opt/ros/humble/share/mirte_base_control/config/mirte_base_control.yaml
\end{verbatim}

using:

\begin{verbatim}
sudo nano
\end{verbatim}

Set:

\begin{verbatim}
P = 0.5, I = 2.0, D = 0.0
\end{verbatim}

for all motors.

On the MIRTE, execute the following commands:

\begin{verbatim}
ros2 run mirte_test mirte_master_set_voltage_ranges
ros2 run mirte_test mirte_master_calibrate
\end{verbatim}

Turn off ROS2 on the MIRTE and reassemble the arm components so they match the \texttt{"home"} pose.
